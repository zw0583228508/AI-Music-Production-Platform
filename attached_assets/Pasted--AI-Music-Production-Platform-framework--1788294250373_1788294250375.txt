# AI Music Production Platform — תוכנית הבנייה מעכשיו

המטרה מעכשיו היא לא לבנות עוד framework כללי. המטרה היא להגיע למערכת שבה:

Audio/Vocal אמיתי
→ ניתוח אמיתי
→ SongModel אמיתי
→ Harmony אמיתי
→ Arrangement אמיתי
→ MIDI/Audio אמיתי
→ Performance
→ ספריות כלי נגינה אמיתיות
→ Mix/Master
→ Export

אין להוסיף abstraction חדש אלא אם הוא נחוץ ישירות לאחד השלבים הבאים.

---

# שלב 1 — לסגור ACE-Step End-to-End באופן מלא

ACE-Step כבר מחובר ל-GPU ולכן הוא כרגע המודל הראשון שצריך להפוך ליכולת מוצר מלאה.

להשלים Production Flow:

Project Source Artifact
→ Signed source URL
→ ACE-Step Modal Worker
→ GPU inference
→ Generated WAV
→ Candidate artifact
→ Quality evaluation
→ Candidate selection
→ Studio playback
→ WAV export

להשלים בפועל את כל המצבים:

COMPLETE
LEGO
REPAINT
COVER
EXTRACT

## COMPLETE

Input:

* vocal/source audio
* SongModel
* StyleSpec
* BPM
* key
* meter
* arrangement instructions
* seed

Output:

* accompaniment WAV
* model/checkpoint provenance
* candidate score
* artifact lineage

## LEGO

לאפשר יצירת שכבה אחת בלבד.

Supported families:

drums
percussion
bass
piano
keys
guitar
strings
brass
synth
orchestral
melody/harmony layer

לדוגמה:

Vocals + piano
→ LEGO drums

Vocals + drums + bass
→ LEGO strings

כל שכבה חדשה חייבת להישמר כ-Artifact נפרד.

## REPAINT

לתמוך ב:

bar range
beat range
time range

ולהמיר bar/beat לזמן לפי TempoMap.

לבצע crossfade בין:
original
generated region
original

לא להחליף את כל הקובץ.

## COVER

Source audio

* StyleSpec
  → style-transformed candidate

## EXTRACT

להשתמש בו כיכולת משנית בלבד.
BS-RoFormer יהיה separator ראשי.
